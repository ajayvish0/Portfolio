PDF-Chat lets you upload a PDF and ask questions about it in plain language. The backend is FastAPI, the interface is React, and conversations and metadata live in PostgreSQL.

## Conversational querying with LangChain

LangChain handles the NLP pipeline: it splits documents, retrieves the passages that matter for a question, and passes them to the language model to answer. The answers reach an 85% response relevance rate.

## Async all the way through

FastAPI's asynchronous request handling keeps slow work — reading documents, calling the model — from blocking other requests. Moving to async endpoints cut API response times by 50%.

## Storage in Google Drive

Uploaded documents are stored through the Google Drive API rather than on the application server. It supports documents up to 50MB with 99.9% data integrity.
