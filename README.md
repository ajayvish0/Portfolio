# Ajay Vishwakarma — AI Full Stack Engineer

Personal portfolio of Ajay Vishwakarma: real-time AI voice agents, call infrastructure, and LLM-powered full stack products.

---

## 🛠️ Engineering Stack

| Layer | Technologies |
| :--- | :--- |
| **Frontend** | Next.js (App Router), React, TypeScript, Tailwind CSS, Redux Toolkit |
| **Backend** | Node.js, Express.js, Nest.js, FastAPI, Socket.IO |
| **AI / GenAI** | OpenAI GPT-4o, LangChain, LangGraph, RAG, AI Agents, MCP |
| **Data & DevOps** | PostgreSQL, MongoDB, MySQL, Docker, AWS, CI/CD |

---

## 📂 Key Projects

- **Property Voice AI**: Real-time voice negotiation trainer against an emotionally adaptive GPT-4o seller, with barge-in and post-call scoring.
- **PDF-Chat Application**: Conversational document querying with FastAPI, LangChain, React, PostgreSQL, and Google Drive.
